# Portfolio – Aziz, développeur full-stack freelance

> Vous avez un projet digital ? Donnons-lui vie ensemble.

Portfolio professionnel présentant mes services de développement web et mobile, mes réalisations et un formulaire de demande de projet.

**Site en ligne : https://TON-SITE.netlify.app**

## Points forts

- **Scène 3D interactive** : des milliers de particules (Three.js) qui prennent la forme de chaque service au défilement (site web, application mobile, portfolio, plateforme full-stack, IA).
- **Méthode animée** : un lecteur façon vidéo en 4 chapitres, de l’idée à la mise en ligne.
- **Réalisations** : projets mis en avant avec aperçu, technologies et liens.
- **Contact** : WhatsApp, email et formulaire de demande (Netlify Forms avec notification par email).
- **Thème clair et sombre**, design responsive, accessibilité (navigation au clavier, réduction des animations respectée).

## Technologies

HTML, CSS, JavaScript, Three.js, Netlify (hébergement et formulaires).

## Structure

```
portfolio/
├── index.html   # tout le site (HTML, CSS et JavaScript)
├── robots.txt   # indexation par les moteurs de recherche
└── README.md
```

## Modifier le contenu

Toutes les informations se trouvent dans le bloc `PORTFOLIO` en haut du script de `index.html` : nom, email, WhatsApp, réseaux sociaux, outils et projets. Pour ajouter un projet, copier le modèle commenté dans la liste `projects`.

## Déploiement

Le dépôt est relié à Netlify : chaque `git push` sur la branche `main` met le site à jour automatiquement.
